# UniCore System

UniCore is a modern, integrated university operations management system built to enhance campus efficiency and student experience. The platform serves as a centralized hub for managing various university services, from resource allocation to maintenance tracking.

## Work Scope

### 1. User Management & Security
- **Secure Authentication**: Integration with Google OAuth2 for seamless login.
- **Role-Based Access Control (RBAC)**: Distinct permissions for Students, Staff, and Administrators.
- **User Profiles**: Personalized dashboards and profile management.

### 2. Resource & Booking Management
- **Resource Tracking**: Real-time availability of campus assets (labs, equipment, etc.).
- **Booking System**: Streamlined reservation process with automated conflict checks.

### 3. Maintenance & Incident Ticketing
- **Lifecycle Management**: End-to-end tracking of maintenance requests.
- **Incident Reporting**: Real-time reporting and status updates for campus incidents.
- **Communication**: Integrated commenting system for coordination between staff and requesters.

### 4. Notification System
- **Real-time Alerts**: Instant notifications for booking updates and ticket status changes.
- **Operational Updates**: Campus-wide announcements and alerts.

### 5. Smart Campus Operations Hub
- **Admin Dashboard**: Comprehensive data visualization and management of all campus activities.

## Technology Stack
- **Backend**: Java, Spring Boot 3, Spring Security (JWT + OAuth2), Hibernate.
- **Frontend**: React (Vite), Vanilla CSS.
